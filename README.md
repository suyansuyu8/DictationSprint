# Dictation Sprint —— 使用说明

> 本应用是一个 本地优先（Local‑first） 的英语听写训练与评测小工具：每天 10 句，先听写、再比对、立刻纠错，并自动汇总 WER（词错误率） 与 WPM（输入速度）；支持前后测导入比较、近 7/14/30 天趋势可视化、按日期范围导出与归档、错词清单导出、一键生成 20 句复训集等。

## 1. 快速开始（5 分钟）

1) 解压整个压缩包到任意文件夹（不要直接双击 `index.html` 打开）。  
2) 启动本地服务器（任选其一）：  
   - macOS/Linux：双击或在终端运行 `./start.sh`  
   - Windows：双击 `start.bat` 
   脚本会自动打开浏览器访问：`http://localhost:8000/app/`
3) 进入训练页，点击“下一句”开始：  
   - 播放器会加载音频（默认示例数据使用占位音频路径）。  
   - 在输入框中键入你听到的句子，点“提交比对”。  
   - 页面会显示对齐结果（正确、替换、删除、插入），并计算 WER/WPM。  
   - 勾选“将错词加入复训清单”可积累需要重点复训的词。
4) 保存/导出：  
   - “保存本地”将状态写入浏览器 LocalStorage（自动也会写入）。  
   - “导出 JSON/CSV”会导出当日会话的数据文件。

## 2. 环境与支持

- 浏览器：推荐 Chrome / Edge。Safari/Firefox 也可，但最优体验在 Chrome/Edge。  
- 系统：Windows / macOS / Linux。  
- 本地服务器：脚本使用 `python -m http.server`，无需安装额外依赖。  
- 联网：不要求，数据均存本机浏览器；可以定期导出备份。

## 3. 应用结构与文件说明

```
<解压目录>/
├─ app/
│  ├─ index.html         ← 主页面，双击无效，请通过 localhost 访问
│  ├─ styles.css         ← 样式表
│  ├─ app.js             ← 前端逻辑（评分、可视化、导出等）

│  ├─ sentences.csv      ← 上述清单的 CSV 版本（可选）

├─ start_local_server.ps1← Windows PowerShell 脚本
├─ start_local_server.bat← Windows 批处理脚本
```

## 4. 准备句子与音频（必读）

### 4.1 建议工作量
- 训练集：每天 10 句 × 14 天 ≈ 140 句  
- 评测集：前测 50 句 + 后测 50 句（不与训练集重叠）  
- 总计：约 240 句（240 条音频）

### 4.2 句子规范
- 长度：每句 6–14 个词，平均 9–11 个词为宜。  
- 内容：覆盖日常/学术/职场，不要只用同一主题。  
- 难度：从简单到稍复杂，逐步引入从句/被动/连读等。

### 4.3 音频规范
- 时长：3–8 秒/句。  
- 格式：建议 `44.1kHz`、单声道、`mp3/wav`。  
- 命名：和 `sentences.json` 中 `audio` 字段一致，例如：`assets/s001.mp3`。  
- 音频文件统一放入 `app/assets/` 目录。

### 4.4 编辑 `sentences.json`
文件每项形如：
```json
{
  "id": "s001",
  "text": "Learning a language takes consistent daily practice.",
  "audio": "assets/s001.mp3"
}
```

## 5. 日常训练流程

1) 点击 “下一句” 播放音频；建议先听 1–2 遍再打字。  
2) 在输入框中完整键入所听句子，点击 “提交比对”：  
   - 页面显示逐词对齐：`绿色=正确`，`蓝色=插入`，`橙色=删除`，`红色删除线=替换`。  
   - 指标：  
     - WER（Word Error Rate） 越低越好；  
     - WPM（Words Per Minute） 越高越好（按实际输入时间计算）。
3) 勾选 “将错词加入复训清单” 可积累高频薄弱词。  
4) 目标每天 10 句；顶部会显示 今日进度（如 7/10）。  
5) 可随时点 “保存本地”；当天训练完成后，建议 导出 CSV/JSON 备份。


---

## 6. 评测面板：前/后测导入与趋势曲线

- 前/后测导入：
  1) 在 “评测面板” 中选择前测文件（JSON 或 CSV）与后测文件；  
  2) 点击 “导入并比较”；  
  3) 页面显示两组 WER/WPM 中位数与差值（WER 负值=提升，WPM 正值=更快）。
  > 建议前/后测各 50 句，主题与难度分布相近且不与训练集重叠。

- 趋势曲线：  
  - 顶部切换 近 7/14/30 天；曲线为滑动中位数（窗口 ≤7），可更稳地反映趋势。  
  - 如空白，表示近 30 天无日志；先做几次训练再看。


---

## 7. 指定日期范围导出/合并与归档清理

1) 选择 开始/结束日期（含边界）。  
2) 导出 JSON/CSV：将所选范围内的每天日志汇总合并。  
3) 归档并清理：导出一个归档 JSON，同时删除本地对应日期的会话键（`ds50_YYYY-MM-DD`）。  
   - 不可撤销：清理前请先导出备份。  
   - 清理后建议点击“刷新曲线”。


---

## 8. 错词清单导出与一键生成 20 句复训集

- 导出错词清单 CSV：包含 `word, count, last_seen, example_sentence, cloze_sentence`。  
  - `cloze_sentence` 会把目标词替换为 `_____`，可用作填空练习。

- 一键生成 20 句复训集：  
  - 根据错词词频自动拼装 20 句英文复训集，并导出：  
    - `review_set_YYYYMMDD.json`  
    - `review_set_YYYYMMDD.csv`  
    - 音频占位清单 `review_set_YYYYMMDD_audio_manifest.txt`（方便后续录音/配音）。  
  - 你可以录制对应音频并放到 `app/assets/`，再导入为新的训练集使用。

## 9. 隐私、安全与备份

- 本应用不上传任何数据；所有训练日志都在你的浏览器里（LocalStorage）。  
- 建议每周导出一次 JSON/CSV 并备份到网盘/本地硬盘。  
- 如需迁移电脑：导出合并 JSON，然后在新设备上导入或保留为独立记录参与统计。

## 10. 常见问题（FAQ）

Q1：双击 `index.html` 打开是空白/音频不加载？  
A：请务必通过 `http://localhost:8000/app/` 访问。直接 `file://` 打开会触发浏览器的本地资源限制。

Q2：音频不播放/找不到？  
A：检查 `app/assets/` 是否存在音频；`sentences.json` 的 `audio` 路径是否匹配；浏览器标签页是否被静音。

Q3：趋势图不显示？  
A：近 30 天没有有效训练日志；先做几句，或者确认浏览器没有阻止 LocalStorage。

Q4：导入 CSV 提示失败？  
A：首行应包含列：`session,sid,ms,tmin,wer,wpm,ref,hyp,ops`（导出样例可作模板）；或直接用 JSON。

Q5：如何“清零”重来？  
A：在“指定日期范围导出/合并”卡片里使用归档并清理；或在浏览器开发者工具中手动清理 `localStorage` 的 `ds50_YYYY-MM-DD` 键。

Q6：能否在同一浏览器多账号使用？  
A：建议不同系统用户或不同浏览器分开；或约定不同的日期范围，导出后再做合并分析。

## 11. 可定制与扩展

- 计划参数：把“每日 10 句 × 14 天”改为任意组合（如 15×21），只是导出统计会按实际日志计算。  
- 评测设计：前/后测的句子数量、主题分布、难度梯度都可根据项目需要调整。  
- UI/样式：`styles.css` 可自定义配色与字号。  
- 导出结构：可以把导出的 JSON/CSV 喂给外部统计工具（如 R/Python/Excel）做更复杂分析。

## 12. 导出字段字典

- `session`：会话日期（`YYYY-MM-DD`）。  
- `sid`：句子 ID（来自 `sentences.json` 的 `id`）。  
- `ms`：提交时间的 Unix 毫秒时间戳。  
- `tmin`：本句从开始到提交的用时（分钟）。  
- `wer`：词错误率（替换 + 删除 + 插入）/ 参考词数。  
- `wpm`：每分钟输入词数（按假设的词边界划分统计）。  
- `ref`：参考文本（原句）。  
- `hyp`：你的输入文本。  
- `ops`：对齐操作序列（`M=匹配` `S=替换` `D=删除` `I=插入`），用于复算 WER。

> 评测面板的中位数是按每条记录的 WER/WPM 先取样本，再做中位数。
